## 현재 적용 범위

이 기록은 앱을 로컬 시뮬레이터·에뮬레이터에서 잰 결과다. 서버 부하 시험이 아니며 AWS에 요청을 보내지 않았다. 운영 API·실제 계정·사용자 데이터로 부하를 만들지 않았다. 실기기 측정은 [iPhone 15 실기기 기록](/performance/09-20261103-device-cpu-and-gzip)에 있다.

- 변경: [PR #1570](https://github.com/OneOrThree/phone/pull/1570)(GROMO-2714, 2026-11-03 main 병합).
- 원문: [`docs/engineering/app-refactoring-2026-11/`](https://github.com/OneOrThree/phone/blob/1281cbfc4559ba3bbe991c8acd529e66257cc5fc/docs/engineering/app-refactoring-2026-11/comparison.md) (comparison·baseline·changes·lifecycle·rendering·bundle·assets·regression-matrix).
- 기준 코드 `fd2881a4f`. 변경 후는 이 기준 위의 작업 브랜치다.

## 측정 조건

- 앱: `app/app-dev`, Release, DEMO 모드(서버 응답 대신 고정 목업). PostHog·Sentry 전송값을 비우고 Airbridge는 DEMO 조건으로 껐다.
- 전후 lockfile·의존성·네이티브 설정을 같게 유지했다.
- iOS: Xcode 26.6(17F113), iPhoneSimulator SDK 26.5, 전용 iPhone 17 / iOS 27.0 시뮬레이터. 서명하지 않은 arm64 Simulator `.app`.
- Android: 전용 API 37 arm64 에뮬레이터, 측정 전용 로컬 키로 서명한 arm64 Release APK.
- iOS 27.0.1 런타임은 설치되어 있지 않아 이 버전에서 검증했다고 표시하지 않는다. 실기기 설치는 하지 않았다.
- 새 설치 5회와 데이터를 유지한 재실행 5회를 나눴다. 새 설치는 이 앱만 지운 것이며 OS 파일 캐시까지 비운 콜드 부팅이 아니다.
- 첫 화면 시간: launch 명령 시작부터 홈의 집중 버튼·퀘스트 종이·섬 지형·상점 지붕·고양이 초상이 함께 보이는 스크린샷까지. `simctl`/`adb` 명령과 캡처 비용이 들어 있다.
- CPU: 홈 확인 5초 뒤 10초 구간, 한 코어 100% 기준 프로세스 CPU. 메모리: iOS footprint(MB), Android TOTAL PSS(MiB). 두 플랫폼의 메모리를 직접 비교하지 않는다.
- 최종 측정은 다른 플랫폼 앱을 멈추고 iOS 전→후, Android 전→후 순서로 직렬 실행했다. 판정이 불완전했던 초기 탐색 측정은 제외하고 원값을 따로 보관했다.
- 호스트는 전용 실험실이 아니다. 배경 시스템 부하까지 통제했다고 보지 않는다.

## 12분 같은 프로세스 관찰 (iOS footprint MB)

같은 PID로 홈→상점→홈→집중 자리 선택→홈을 10회 왕복했다. 두 버전 모두 720초 이상 실행했고 프로세스 종료·자동화 실패는 없었다.

| 시점 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 시작 | 178 | 178 |
| 첫 왕복 후 | 318 | 315 |
| 열 번째 왕복 후 | 387 | 387 |
| 12분 종료 | 388 | 388 |

처음 장면을 연 뒤 ImageIO가 약 29→107MB가 되고 끝까지 107MB였다. MALLOC_LARGE 등도 늘어 전체 증가를 이미지 캐시 하나로 설명하지 않는다. 장시간 heap·할당 추적이 더 필요하다.

## 렌더 횟수와 자원 수명

- 별도 테스트 사본에서 기존 렌더 카운터 13개를 출력했고 전후 모두 같았다. 홈 5초 대기 중 지도 추가 렌더 0, 걷기 1, 드래그·핀치 중 0·손 뗀 뒤 1.
- 이 횟수는 지도 전체 갱신의 대리 지표다. React Profiler commit 시간이나 GPU 프레임 수가 아니다.
- 표시용 시계(`useNow`·App의 초 경계 예약)가 배경에서도 살아 있던 것을 배경에서 멈추고 복귀 때 현재 시각을 반영하게 했다. 테스트에서 배경 60초 동안 콜백·예약 0, 10회 구독·해제 뒤 남은 타이머·리스너 0을 확인했다. 원문은 이것을 배경 예약 제거로만 쓰고 전경 렌더 감소로 쓰지 않는다.
- 어떤 뷰에도 연결되지 않은 항해 애니메이션 예약을 지웠다. 실제 항해 컷신은 그대로다.

## 검증

- 전체 Jest: 변경 전 267개 스위트 / 4,603개, 변경 후 267개 스위트 / 4,580개 통과. 삭제한 이전 화면 전용 29개를 지우고 수명 계약 6개를 더했다.
- typecheck·lint·format:check, iOS/Android/Web export, iOS·Android Release 빌드 통과.
- 이미지 생성 검사 중 영문 도장 검사는 전후 모두 같은 파일에서 실패한다. 파일은 바꾸지 않았다. 전체 생성 검사 통과로 표시하지 않는다.

## 한계

- 실제 계정 로그인·원격 서버·실기기 촬영·푸시·네이티브 앱 차단은 이번 DEMO 측정 범위 밖이다.
- 모든 언어·태블릿·긴 목록·다수 고양이 장면의 실기기 GPU 프로파일은 수집하지 않았다.
- 남은 큰 모듈(`App`, `WorldMap`, 회관·게시판)과 인증 런타임 순환은 후속 대상이다.
- 이 측정과 [iPhone 15 실기기 측정](/performance/09-20261103-device-cpu-and-gzip)은 기기·빌드·지표가 달라 한 표로 합치지 않는다.
