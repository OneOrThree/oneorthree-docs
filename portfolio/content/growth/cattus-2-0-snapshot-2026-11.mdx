## 이 기록을 읽는 법

- 수치는 팀이 2026-11-05~11-14에 조회해 남긴 기록에서 옮겼습니다. 이 문서를 쓰면서 다시 조회하지 않았습니다.
- 정본은 팀의 비공개 성과 대시보드입니다. 여기에는 집계 수치와 기준만 싣습니다.
- 같은 이름의 지표라도 원천·기준·조회 시각이 다르면 다른 줄에 둡니다. 두 줄을 더하거나 비율로 바꾸지 않습니다.
- 매체가 보고한 설치(Meta·Google), 귀속 도구의 설치(Airbridge), 앱 첫 실행(PostHog)은 서로 다른 값입니다. 합산하지 않습니다. 스토어 콘솔 다운로드 수는 모으지 않았습니다.
- 시각은 KST입니다.

| 원천 | 무엇을 세나 | 주의 |
| --- | --- | --- |
| PostHog | 앱이 보낸 이벤트(`app_active`, 첫 실행, `focus_completed` 등) | 내부·테스트 사용자 필터를 켰다고 적힌 값만 그렇게 표시합니다 |
| 운영 DB 읽기 전용 조회 | 계정·섬·집중 정산 기록 | 탈퇴 계정 제외. 「앱만 연 사람」은 DB에 남지 않습니다 |
| Datadog 로그 | nginx 요청, Realtime 연결 로그 | 운영 로그는 10-28 이전이 없고, nginx JSON 로그는 10-31부터입니다 |
| Meta 광고 관리자, Google Ads | 광고비, 매체가 센 설치·전환 | 매체 기준 귀속입니다 |
| Airbridge | 귀속 도구가 센 설치 | 11-03부터 집계 |

- 원천: PostHog. 신호는 `app_active`(로그인한 상태로 앱을 앞으로 띄울 때마다 보냄). 로그인 뒤 사람을 계정에 묶으므로 계정 기준에 가깝습니다.
- 「내부·테스트 사용자 제외」 필터를 켰습니다. 운영 환경 조건을 더해도 값이 같았습니다.

함께 집중한 사람이 더 오래, 더 자주 집중했다는 관측입니다. 원래 열심히 하는 사람이 함께 집중을 고를 수 있습니다(자기 선택). 팀원 계정도 빼지 못했습니다. 이 표로 「함께 집중하면 오래 한다」고 결론 내리지 않습니다.
</Callout>

## 운영 최대 동시 접속과 초당 요청 (11-12 조회)

실제 이용에서 관측한 최대치입니다. 서버가 버틸 수 있는 한계가 아닙니다. 수용량 시험 기록은 [부하테스트 타임라인](/performance/01-loadtest-timeline)에 있습니다.
