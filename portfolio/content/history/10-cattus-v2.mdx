## 제품과 코드의 기준이 바뀌었다

활성 앱은 Cattus 2.0이며 Gromo 1.x는 `app/legacy/app-dev/`에 동결되어 있습니다. 섬 통장·건설·친구 편지·항해와 현재 용어는 [제품 안내](/spec/context)에 모았습니다. 9월의 같이숲·R61 문서는 현재 제품이 나오기까지의 기록으로 남습니다.

## 편지·채팅·이동의 경계를 분리했다

친구 편지는 Data, 우리 섬 채팅방은 Realtime에 저장합니다. 현재 앱 채팅은 REST·폴링을 사용하며, 이동은 Redis lease·epoch를 통해 여러 Realtime 인스턴스가 같은 섬 소유자를 찾는 구조입니다. 현재 상태는 [통신 안내](/spec/messaging-and-realtime)에 있습니다.

## 10월 22일 — 성능 기록과 구현을 나눴다

당시 AWS 측정은 연결 유지뿐 아니라 종료 후 OOM·회복까지 판정했고, 이후 코드와 로컬 메모리 대조를 별도로 기록했습니다. [실험 타임라인](/performance/01-loadtest-timeline)의 수치는 당시 환경에 한정됩니다. V2 전환 뒤의 현재 수용량을 다시 측정했다는 뜻은 아닙니다.

## 11월 2일 — 구 환경을 정리했다

운영 문서에 따르면 구 서버·DNS·워크플로를 정리하고 AWS 운영 V2와 GCP dev V2를 사용하도록 맞췄습니다. 운영 서버·Kafka·Redis는 release 발행 뒤 수동 CD, 백오피스는 main에서 승인 배포하는 경계입니다.

## 11월 3일 — 읽는 문서도 같은 기준으로 맞췄다

[phone PR #1568](https://github.com/OneOrThree/phone/pull/1568)에서 README의 서버·편지·배포 설명과 바로가기를 갱신했습니다. 이 사이트도 그 머지 커밋을 기준으로 현재 안내를 다시 썼습니다. 과거 기록의 날짜와 측정값은 유지하고 현재 안내와 연결했습니다.
