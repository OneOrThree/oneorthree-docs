## 제품의 중심 흐름

사용자는 고양이가 되어 섬에 들어가고, 낚시섬에서 집중하거나 뗏목으로 항해합니다. 집중으로 모은 물고기는 섬 통장에 쌓입니다. 주민은 시설을 이용하고, 섬장은 건설 목표를 정해 섬을 키웁니다.

개인 지갑에 보상을 쌓던 Gromo 1.x와는 경제·소속·화면 구조가 다릅니다. 1.x의 그룹 챌린지·내기·시간조각·개인 리그를 현재 Cattus의 기능으로 설명하지 않습니다.

## 이름과 저장소

| 표현 | 뜻 |
| --- | --- |
| Cattus | 현재 제품 이름 |
| 집중할고양 · cattus | 한국어·그 밖의 언어에서 보이는 앱 이름 |
| 같이숲 · R61 | 2026년 9월 재설계 단계의 이름과 설계 기준 |
| Gromo 1.x | 스토어 1.1.0까지의 동결된 이전 앱 |
| `app/app-dev/` | 활성 2.0 앱 |
| `app/legacy/app-dev/` | 동결된 1.x 코드 |

Jira 키 `GROMO`, 호스트·태그의 `catus`, 경로의 `fishcat`, 코드 패키지 `group`은 기존 식별자라 그대로 둡니다.

## 함께 쓰는 용어

| 용어 | 의미와 구분 |
| --- | --- |
| 주민·섬장·방문자 | 가입한 사용자·관리 권한을 가진 주민·가입하지 않고 구경하는 사용자 |
| 메인 섬·현재 섬 | 대표로 정한 소속 섬·지금 들어가 있는 섬. 현재 섬을 바꿔도 대표 섬은 유지 |
| 물고기·섬 통장 | 섬 소유의 재화와 잔액. 개인 물고기 지갑 없음 |
| 낚시섬·항해·휴식 | 섬에서의 집중·먼바다에서의 집중·집중 적립을 멈추는 상태 |
| 우체통 | 친구 편지·시스템 편지·고양이 잡지를 받는 시설 |
| 우리 섬 채팅방 | 같은 섬 주민의 단체 채팅. 친구 편지와 별도 저장소·API 사용 |
| 도서관 | 내 일기장·이웃 일기장에서 집중과 폰 사용 기록을 확인하는 시설 |
| 전망대·망원경 | 섬 주간 순위·검색을 보는 시설과 항해할 섬 목록 |
| 운영진의 편지 | 백오피스에서 게시한 개발자 공지를 앱에서 한 번 보여 주는 안내 |

## 플랫폼별 기능

iOS는 네이티브 Screen Time 확장으로 허용 앱 밖의 앱을 집중 중 차단합니다. Android는 사용 시간 측정과 위젯·일반 푸시를 지원하지만 현재 `supportsFocusShield=false`이며 집중 차단 기능은 제거된 상태입니다. 두 플랫폼의 차단 경험이 같다고 설명하지 않습니다.

카메라로 손과 공부 도구를 확인하는 AI 집중 측정은 선택 기능입니다. 설치본·런타임·권한에 따라 가능한 기능이 달라지므로 네이티브 변경은 OTA만으로 배포하지 않습니다.
