## 상태를 읽는 기준

| 표시 | 뜻 |
| --- | --- |
| 구현 | 기준 커밋(main `1281cbfc4`)에 코드가 있다 |
| 운영 기록 | 저장소의 배포 기록이 운영 반영을 남겼다. 운영 서버 4종은 `catus-v2.0.14-V2`(2026-11-14 02:32 KST, main #1665까지), 백오피스는 `backoffice-v1.0.9-V2`(2026-11-10) |
| main에만 | 코드는 있지만 위 운영 태그 뒤에 머지됐다(#1668~#1675) |
| 실기기 확인 | 설치한 바이너리와 환경에서 따로 확인해야 한다 |

이번 문서 갱신은 새 출시 판정이나 부하 검증이 아닙니다. 앱은 iOS `app-2.3.7-ios-14`, Android `app-2.3.26-android-906` 태그가 2026-11-13에 있습니다. 스토어 공개 여부는 이 문서에서 판정하지 않습니다.

## 조건부 동작과 남은 확인

- Realtime의 현재 membership authorization, 차단 필터, Kafka 소비는 별도 플래그입니다. 운영값은 저장소 기본값만으로 판단하지 않습니다.
- Data의 outbox relay와 Notification의 Kafka 수신·스케줄링은 2026-11-09부터 배포 프로필 기본값이 켜짐입니다. 실제 발송에는 발송 제어값과 FCM 자격도 필요합니다.
- 상점 발행본 v1 밖의 상품(소품·섬 테마·음원) 가격과 기본 곡 지급 방식은 미결입니다. 신발 꾸미기 10종은 그림이 생기면 같은 가격으로 열립니다.
- Android 집중 중 앱 복귀는 새 네이티브 서비스라 OTA로 배포할 수 없습니다. 스토어 프로덕션 승격은 이 범위의 결정 밖입니다. iOS 실드와 같은 기능으로 표시하지 않습니다.
- 바다 항해 중 자리를 비운 시간을 빼는 방식은 정하지 않았습니다. 앱 이탈 규칙은 섬 집중에만 적용합니다.
- 다국어는 앱 화면의 한국어·영어 누락을 보완했습니다. 서버·운영 콘텐츠·백오피스·네이티브 확장의 번역은 범위 밖입니다.
- 이미지 CDN은 dev 시범 경로이며 운영 CDN이 준비되지 않아 운영 빌드·런타임에서 사용을 막는 코드가 있습니다.
- 네이티브 SDK·푸시·자산 모듈 변경에는 새 바이너리가 필요합니다. OTA 런타임과 서버 선행 배포 게이트를 확인합니다.

## 출시 순서

서버 의존 API가 있는 앱 변경은 서버 운영 배포가 먼저입니다. 신고 접수처럼 새 공개 경로가 필요한 기능은 Data 마이그레이션 → Data·Business 서버와 nginx 경로 → 앱 순서입니다. 퀘스트 삭제(#1673)와 회관 홍보 칸 카드(#1670)도 서버 #1672·#1669가 운영에 나간 뒤에 앱을 내야 합니다.

`app-server-gate.py`는 마지막 운영 성공 태그와 앱 HEAD의 서버 런타임 차이를 검사합니다. 실패·진행 중 CD나 기록 조회 실패는 출시 가능으로 보지 않습니다. 이 게이트는 Infra·시크릿 등 모든 의존성을 잡지는 못합니다. 따라서 앱이 필요로 하는 공개 경로와 설정은 PR에서 함께 확인합니다. [현재 배포 절차](/operations/06-v2-deployment)

## 보존하는 이전 제품

Gromo 1.x의 시간조각·그룹 챌린지·내기·개인 리그, 과거 스토어 성과와 실험은 연대기·연구·ADR에 남깁니다. 이 기록을 현재 Cattus의 기능 목록이나 향후 확정 일정으로 옮기지 않습니다.
