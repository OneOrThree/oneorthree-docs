## 상태를 읽는 기준

‘구현’은 기준 커밋에 코드가 있다는 뜻입니다. ‘운영 기록’은 저장소 문서가 기록한 배포 상태이며, ‘실기기 확인’은 설치한 바이너리와 환경에서 확인해야 합니다. 이번 문서 갱신은 새 출시 판정이나 부하 검증이 아닙니다.

## 현재 구현 범위

| 영역 | 확인한 코드 범위 | 함께 볼 조건 |
| --- | --- | --- |
| 계정·소속 | 게스트/소셜, 온보딩, 주민·초대·섬 관리 | 명령별 게스트·섬장 권한과 설정 |
| 집중·항해 | 섬/바다 세션, 휴식, 상태 복구, 물고기 정산 | 세션 정본·날짜 축·동시성 |
| 공동 성장 | 섬 통장·원장, 건설, 퀘스트 | 착공 권한, 시설, 보상 중복 방지 |
| 기록·탐색 | 도서관, 주간 순위, 망원경, 잡지 | 조회 범위와 데이터 발행 상태 |
| 소통 | 친구·편지·시스템 편지, 우리 섬 채팅방 | 소셜 로그인, 시설·차단, REST 폴링 |
| 외양·상점·음악 | 보유품·외양, 상품 조회/구매, 재생 | 승인된 상품·가격·보유와 구매 권한 |
| 실시간 | 집중·휴식·응원·섬 사건·이동·바다 | 열려 있는 destination과 설정 |
| 백오피스 | 공지·운영진의 편지·잡지·정책·출시 현황 | 별도 환경 승인·서버 계약 호환 |

## 조건부 동작과 남은 확인

- Realtime의 현재 membership authorization, 차단 필터, Kafka 소비는 별도 플래그입니다. 운영값은 저장소 기본값만으로 판단하지 않습니다.
- 상점의 공개 API가 있어도 활성 상품 발행본·가격이 없으면 구매할 수 없습니다. 보유품 적용과 신규 구매를 구분합니다.
- Android 집중 차단은 제거되어 있습니다. 일반 FCM 푸시·측정·위젯이 있다고 iOS 실드와 같은 기능으로 표시하지 않습니다.
- 이미지 CDN은 dev 시범 경로이며 운영 CDN이 준비되지 않아 운영 빌드·런타임에서 사용을 막는 코드가 있습니다.
- 네이티브 SDK·푸시·자산 모듈 변경에는 새 바이너리가 필요합니다. OTA 런타임과 서버 선행 배포 게이트를 확인합니다.

## 출시 순서

서버 의존 API가 있는 앱 변경은 서버 운영 배포가 먼저입니다. `app-server-gate.py`는 마지막 운영 성공 태그와 앱 HEAD의 서버 런타임 차이를 검사합니다. 실패·진행 중 CD나 기록 조회 실패는 출시 가능으로 보지 않습니다.

이 게이트는 Infra·시크릿 등 모든 의존성을 잡지는 못합니다. 따라서 앱이 필요로 하는 공개 경로와 설정은 PR에서 함께 확인합니다. [현재 배포 절차](/operations/06-v2-deployment)

## 보존하는 이전 제품

Gromo 1.x의 시간조각·그룹 챌린지·내기·개인 리그, 과거 스토어 성과와 실험은 연대기·연구·ADR에 남깁니다. 이 기록을 현재 Cattus의 기능 목록이나 향후 확정 일정으로 옮기지 않습니다.
