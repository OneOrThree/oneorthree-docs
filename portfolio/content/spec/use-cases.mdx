## 먼저 볼 표

| 흐름 | 누가 | 이번 기준에서 달라진 점 |
| --- | --- | --- |
| 시작 | 모든 사용자 | 웹 빌드에서 게스트로 시작해 웹 전용 섬에 들어가는 코드가 있다(현재 공개 주소는 3D 섬 웹) |
| 집중 | 주민 | 차단·복귀가 없는 집중에서 앱을 나가면 휴식, 15초를 넘기면 종료 |

| 퀘스트 | 섬장이 열고 주민이 채움 | 생성·보상 개방. 삭제와 시간대 겹침 금지는 main에만 있음 |
| 상점 | 소셜 로그인 주민 | 그림이 있는 꾸미기만 판매. 운영 기본 발행본 v1 |
| 신고 | 게스트 포함 로그인 사용자 | 메일 링크 대신 앱 안에서 접수하고 접수 번호를 받는다 |

## 시작하고 섬에 들어가기

게스트 또는 소셜 계정으로 시작해 닉네임과 고양이 모습을 정합니다. 섬에 가입하면 주민이 되고, 가입하지 않은 섬은 방문자로 구경합니다. 메인 섬은 대표 소속이고 현재 섬은 지금 보고 있는 소속 섬입니다.

처음 섬에 도착하는 첫 항해 체험의 도착은 서버가 계정당 한 번만 기록합니다. 앱을 다시 설치해 체험을 반복해도 기록은 늘지 않습니다.

새로 만든 섬은 마을회관이 완공된 상태로 시작합니다. 회관 없이 만들어졌던 이전 섬은 별도 운영 명령으로 정리합니다.

앱의 웹 빌드에는 게스트 세션으로 온보딩한 뒤 서버가 배정하는 웹 전용 섬 하나에 주민으로 들어가는 흐름이 있습니다([#1597](https://github.com/OneOrThree/phone/pull/1597)). 이 섬만 정원 제한이 없고, 기존 앱 소속과 강퇴 제약은 그대로 적용합니다. 다만 11-19에 확인한 공개 주소 `try.oneorthree.world`는 이 빌드가 아니라 서버와 연결되지 않는 3D 섬 웹(`app/metaverse-web/`, #1629 기준)을 내보냅니다.

게스트도 집중과 섬 생활을 시작할 수 있지만 친구 요청·편지 발송·상점 구매에는 소셜 로그인이 필요합니다. 9월 R61 그림의 ‘모든 기능 동일 허용’ 설명은 현재 계약이 아닙니다.

## 집중하고 쉬기

낚시섬에서 집중을 시작하고, 모닥불에서 쉬었다가 다시 집중하거나 종료합니다. 휴식 시간은 유효 집중과 물고기 적립에서 제외합니다. 서버의 세션 상태·구간·정산이 최종 기준이며 앱 타이머만으로 지급액을 확정하지 않습니다.

- **앱을 나갈 때**: iOS 차단이나 Android 복귀가 걸리지 않은 섬 집중에서 앱을 나가면 앱이 바로 휴식으로 바꾸고 알림을 예약합니다. 15초 안에 돌아오면 이어서 집중하고, 넘기면 종료해 결과창으로 갑니다. 바다 항해와 이미 휴식 중인 세션은 제외합니다.
- **화면 자동 잠금**: AI 측정을 켜지 않아도 집중 중에는 화면 자동 잠금을 막습니다. 사용자가 직접 잠그면 iOS에서는 나간 것으로 봅니다.
- **AI 집중 측정**: 선택 기능입니다. 카메라로 손과 공부 도구(책·노트북·키보드)를 확인하고, 책이 옆이나 거꾸로 보이면 다른 방향으로 다시 검사합니다. 집중 화면에 측정 상태와 최근 판정을 표시합니다.
- **허용 앱과 측정 앱**: 낚시섬의 통합 안내에서 측정 앱 → 허용 앱 순서로 설정합니다. 측정 앱을 저장하면 사용 시간을 서버로 보내 통계와 퀘스트에 씁니다.
- **별점 요청**: 집중을 세 번째로 끝낸 뒤 OS 기본 별점창을 한 번 요청합니다. 실제로 띄울지는 OS가 정합니다.

같은 섬에서 집중하는 주민에게 응원을 보낼 수 있습니다. 웹소켓 접속 여부와 집중 세션의 생존·보상 판정은 분리합니다. 앱이 꺼졌다 다시 열리면 현재 세션을 조회해 화면을 복구하고, 서버가 이미 닫은 세션이면 「집중이 이미 끝나 있었어요」를 안내합니다.

## 물고기를 모으고 건설하기

물고기는 집중한 섬의 섬 통장에 쌓입니다. 섬장이 다음 건물 목표를 정하는 것과 실제 건설을 시작하며 물고기를 차감하는 것은 별도 명령입니다. 목표 선택만으로 잔액을 차감하지 않습니다.

모든 건물은 섬 통장 잔액이 총 건설비 이상이면 착공할 수 있습니다. 주민별 할당량은 없고, 목표를 바꾸거나 주민이 드나들어도 잔액은 그대로 씁니다. 회관과 게시판의 청사진은 현재 잔액·총 건설비·건설 후 잔액 또는 부족액을 보여 줍니다.

건설 목표·착공은 섬장만 할 수 있고 게스트 섬장도 가능합니다. 상점 상품·음원 공동 구매는 활성 주민 누구나 할 수 있지만 게스트는 제외됩니다. 보유한 섬·건물 테마 적용은 구매와 다른 권한입니다.

## 퀘스트 함께 채우기

섬장이 게시판에서 퀘스트를 엽니다. 시간대 집중 퀘스트(종료는 23:59까지)와 하루 폰 사용 퀘스트가 있습니다. 주민은 달성한 자기 몫을 받고, 전원이 달성하면 보너스가 함께 들어갑니다.

| 항목 | 값·규칙 | 근거 |
| --- | --- | --- |
| 개인 달성 | 물고기 10마리, 섬 통장으로 | 설정 기본값 |
| 전원 달성 보너스 | 대상 주민 수 × 5마리 | 설정 기본값 |
| 출시 스위치 | 없음. 생성·정산이 늘 열려 있다 | 코드, 운영 배포 기록(v2.0.11) |
| 퀘스트 삭제 | 섬장만. 열린 회차도 목록에서 빠지고 다음 회차를 열지 않는다. 이미 받은 보상은 되돌리지 않는다 | main 코드. 운영 서버 미반영 |
| 시간대 겹침 | 같은 섬의 집중 퀘스트끼리 시간대가 겹치면 만들 수 없다. 맞닿은 시간대(19–20시, 20–21시)는 된다 | main 코드. 운영 서버 미반영 |

## 시설 이용하기

| 시설 | 할 수 있는 일 |
| --- | --- |
| 마을회관 | 건설 목표·공동 가계부·주민·섬 관리. 다음 호 잡지 홍보 칸 카드(main에만 있음) |
| 게시판 | 공지·퀘스트·청사진·방명록 |
| 축음기 | 보유 음악 선택과 낚시섬 재생 |
| 도서관 | 내 일기장·이웃 일기장의 집중·폰 사용 기록 |
| 우체통 | 친구 편지·시스템 편지·고양이 잡지 |
| 전망대 | 섬 순위·검색. 순위는 최근 7일 주민 1명당 하루 평균 집중으로 줄 세운다 |
| 상점 | 물고기로 꾸미기·건물 테마 구매 |

시설 완공·주민 자격·활성 상품·가격 등 기능별 조건을 만족해야 합니다. 상점은 활성 발행본에 가격이 있는 상품만 팝니다. 운영에는 발행본 v1(딸기 건물 테마 5종, 머리·목·신발 꾸미기 각 10종)이 있고, 그림이 없는 신발 10종은 숨겨져 지금 보이는 상품은 25개입니다. 건물 테마는 해당 건물을 완공해야 살 수 있습니다.

## 소통하고 항해하기

친구 편지는 비동기 연락이고, 우리 섬 채팅방은 주민들의 단체 대화입니다. 두 기능은 API·저장소·멱등성과 시설 게이트가 다릅니다. [통신 경계](/spec/messaging-and-realtime)에서 비교할 수 있습니다.

뗏목과 망원경에서 행선지를 정하고 먼바다에서 항해합니다. 망원경 목록은 소속 섬 → 가까운 섬 → 찜한 섬 → 무작위 섬 → 무인도 순서입니다. 무인도 항해는 90분이고, 일반 섬 항해 시간은 그대로입니다. 도착 후 섬에 내립니다.

고양이 잡지는 Data 서버가 매일 KST 07시부터 자동 발행합니다. 섬장은 섬 통장 물고기로 다음 호 홍보 칸을 신청합니다. 편집부 소식이 없는 날에는 앱이 편집냥 팁 25개 중 하나를 잡지를 펼칠 때마다 골라 보여 줍니다. 운영진의 편지는 앱이 보낸 플랫폼에 맞는 공지만 보여 줍니다.

섬 이동 프레임은 Realtime이 다루고 가입·잔액·집중 정산은 Data가 다룹니다.

## 신고하고 탈퇴하기

- **신고**: 설정(일반 신고), 사용자 메뉴, 편지, 채팅에서 사유 8종과 상세 내용을 적어 제출합니다. 서버가 접수 번호를 돌려줍니다. 신고는 자동 차단이나 자동 숨김을 하지 않으며, 사용자 차단은 따로 선택합니다. 운영팀이 미종결 신고를 조회해 확인한 뒤 종결합니다.
- **탈퇴**: 탈퇴하면 그 사용자가 주고받은 편지를 본문까지 삭제합니다. 채팅은 다른 주민의 읽음 위치에 필요한 행만 남기고 본문·발신자·클라이언트 식별자를 지웁니다. 다른 사용자끼리의 편지는 남습니다.

신고 접수와 탈퇴 시 삭제는 운영 서버 v2.0.14 범위에 들어 있습니다(배포 기록 기준). 앱 신고 화면이 사용자 기기에 도달했는지는 앱 출시 상태에 따라 다릅니다.
