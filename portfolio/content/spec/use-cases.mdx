## 시작하고 섬에 들어가기

게스트 또는 소셜 계정으로 시작해 닉네임과 고양이 모습을 정합니다. 섬에 가입하면 주민이 되고, 가입하지 않은 섬은 방문자로 구경합니다. 메인 섬은 대표 소속이고 현재 섬은 지금 보고 있는 소속 섬입니다.

게스트도 집중과 섬 생활을 시작할 수 있지만 친구 요청·편지 발송·상점 구매에는 소셜 로그인이 필요합니다. 9월 R61 그림의 ‘모든 기능 동일 허용’ 설명은 현재 계약이 아닙니다.

## 집중하고 쉬기

낚시섬에서 집중을 시작하고, 모닥불에서 쉬었다가 다시 집중하거나 종료합니다. 휴식 시간은 유효 집중과 물고기 적립에서 제외합니다. 서버의 세션 상태·구간·정산이 최종 기준이며 앱 타이머만으로 지급액을 확정하지 않습니다.

같은 섬에서 집중하는 주민에게 응원을 보낼 수 있습니다. 웹소켓 접속 여부와 집중 세션의 생존·보상 판정은 분리합니다. 앱이 꺼졌다 다시 열리면 현재 세션을 조회해 화면을 복구합니다.

## 물고기를 모으고 건설하기

물고기는 집중한 섬의 섬 통장에 쌓입니다. 섬장이 다음 건물 목표를 정하는 것과 실제 건설을 시작하며 물고기를 차감하는 것은 별도 명령입니다. 목표 선택만으로 잔액을 차감하지 않습니다.

건설 목표·착공은 섬장만 할 수 있고 게스트 섬장도 가능합니다. 상점 상품·음원 공동 구매는 활성 주민 누구나 할 수 있지만 게스트는 제외됩니다. 보유한 섬·건물 테마 적용은 구매와 다른 권한입니다.

## 시설 이용하기

| 시설 | 할 수 있는 일 |
| --- | --- |
| 마을회관 | 건설 목표·공동 가계부·주민·섬 관리 |
| 게시판 | 공지·퀘스트·청사진·방명록 |
| 축음기 | 보유 음악 선택과 낚시섬 재생 |
| 도서관 | 내 일기장·이웃 일기장의 집중·폰 사용 기록 |
| 우체통 | 친구 편지·시스템 편지·고양이 잡지 |
| 전망대 | 섬 주간 순위·검색 |
| 상점 | 물고기로 꾸미기·공동 상품 구매 |

시설 완공·주민 자격·활성 상품·가격 등 기능별 조건을 만족해야 합니다. API가 있다는 사실만으로 운영 상품이나 가격이 모두 발행됐다고 판단하지 않습니다.

## 소통하고 항해하기

친구 편지는 비동기 연락이고, 우리 섬 채팅방은 주민들의 단체 대화입니다. 두 기능은 API·저장소·멱등성과 시설 게이트가 다릅니다. [통신 경계](/spec/messaging-and-realtime)에서 비교할 수 있습니다.

뗏목과 망원경에서 행선지를 정하고 먼바다에서 항해합니다. 도착 후 섬에 내리며, 고양이 잡지와 섬 홍보로 새로운 섬을 발견합니다. 섬 이동 프레임은 Realtime이 다루고 가입·잔액·집중 정산은 Data가 다룹니다.
