## 대체하는 결정

[ADR-021](/adr/adr-021-release-fast-forward)의 main→release fast-forward push와 PR close 절차를 대체합니다. 2026-11-03 기준 AGENTS.md와 운영 V2 파이프라인에 적힌 계약을 기록합니다.

## 결정

main → release PR은 Create a merge commit으로 병합해 main 부모 이력을 보존합니다. 일반 코드 검토와 수정은 main PR에서 마치고, 승격에서는 기준 SHA의 기능·수정·운영 변경을 한국어로 요약합니다.

release push는 서버·Kafka·Redis의 불변 산출물과 V2 태그를 발행합니다. 운영 변경은 release에서 수동 CD를 실행하고 환경 승인을 받은 뒤에 일어납니다. 백오피스는 main 머지에서 별도 환경 승인 후 배포합니다.

## 이유와 비용

승격 이력을 보존하고 발행과 실제 적용을 분리합니다. 대신 최신 main, 발행 태그, 마지막 운영 성공 태그가 다를 수 있으므로 각 상태를 따로 보여 줘야 합니다. 앱 출시 게이트는 마지막 운영 성공 기록을 기준으로 확인합니다.

V2 버전은 patch 자동 증가이며 기존 release 버전 라벨을 읽지 않습니다. DB 마이그레이션은 지문 비교와 별도 승인이 필요하고 이미지 복구가 스키마 복구를 의미하지 않습니다.
